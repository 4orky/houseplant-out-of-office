One out-of-office auto-reply written as if a houseplant sent it, 120 characters at most. The program writes one line to `/output/entry.txt`:

> I'm out of the office, slowly dying on the windowsill since March. Please water me — or don't. I can't leave.

## Run it

```sh
python3 main.py
```
