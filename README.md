A single out-of-office auto-reply, written as though the office houseplant
typed it itself. The winning line is 109 characters long and lands in
`/output/entry.txt` once you run the program:

    I'm out of the office, slowly dying on the windowsill since March. Please water me — or don't. I can't leave.

## How to run

    python3 ./main.py

`main.py` drafts twelve candidate replies, grades them against the judge's
brief (plant voice first, then surprise, plant life, tightness and
originality), and writes the best one out. The choice is deterministic:
the same line comes out on every run.
